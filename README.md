# Akshay Kumar Upadhyaya — Wildlife Biologist Website

This is a static website prepared for free hosting with GitHub Pages.

## Local preview

Open `index.html` in a browser, or run a local server from this folder:

```bash
python -m http.server
```

Then visit `http://localhost:8000`.

## GitHub Pages

Create a public repository, upload the contents of this folder, and enable GitHub Pages from **Settings → Pages → Deploy from a branch → main → root**.

## Content notes

The first draft intentionally excludes dates, statistics, counts, measurements, phone numbers, and other numerical claims. Unanswered questionnaire sections were not populated with invented content. Replace or add content only after review and approval.

The supplied images are copied into `photos/` for the website draft. Please confirm image ownership and captions before publishing.
